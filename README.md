# BINDERS / Studies

Architectural mass process, timber assembly and vector floor-plan drawings.

**Live website:** https://songminhyo.github.io/binders-studies/

- **01 / Mass process:** existing seven-stage mass and curved-roof study.
- **02 / Timber assembly:** existing A/B/C timber assembly and joinery studies.
- **03 / Drawings:** overall plan and unified A/B/C detail plans, R02.

## Drawings

[Open the drawing archive](https://songminhyo.github.io/binders-studies/#drawings/overall).
Choose Overall, A, B or C. Drag to pan, pinch or use +/− to zoom, and use
Fit view to reset. Drawing mode frames the plan; Full sheet includes the
complete A1 sheet and information tables. PDF links open the vector originals.

The overall plan uses 1:150. A/B/C detail sheets share an A1 / 1:100 layout.
Architectural geometry and dimension values are retained. The overall plan's
site boundary is removed, and the title-block labels use embedded Pretendard.
All displayed drawing labels are English. SVG lettering is outlined.

## iPad

Open the live link in Safari. For a standalone presentation, use Share →
Add to Home Screen, then launch BINDERS from that icon. An internet connection
is required; this release does not install an offline service worker.
